# Java Learning & Projects

A collection of Java exercises, OOP practice and application projects maintained by **Toufiqul Islam**.

## What's inside

This repository includes coursework and independent practice covering:

- **Java fundamentals:** basic syntax, classes and methods.
- **Object-oriented programming:** encapsulation, inheritance and other OOP exercises.
- **JavaFX projects:** login, registration and desktop application practice.
- **Application exercises:** student management and an AgroLink BD project folder.
